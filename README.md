## Controllers supported by grblHAL

The controller list has been moved to the [documentation site](https://grblhal.org/docs/getting-started/controllers/).

To add to or update the list edit the Excel sheet and update [markdown](https://github.com/grblHAL/grblhal_docs/blob/main/content/markdown/01-Getting-Started/) in the _03-controller-support.md_ file then create a PR for the change. Instructions can be found at the top of the markdown file as html comments.
